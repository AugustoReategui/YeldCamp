## 📖 Overview

**YeldCamp** is a full-stack web application inspired by Yelp, allowing users to discover, create, and review campgrounds worldwide.  
It combines powerful backend technologies with interactive maps, image uploads, and secure authentication for a modern, user-friendly experience.

Built with **Node.js**, **Express**, **MongoDB**, **EJS**, and deployed on **Heroku** — with **Cloudinary** for image hosting and **Mapbox** for geolocation.

---

## 🚀 Features

✨ User registration and login with Passport.js  
✨ Add, edit, and delete campgrounds with photo uploads  
✨ Interactive Mapbox cluster map with clickable pop-ups  
✨ Leave reviews and star ratings  
✨ Cloud image hosting (Cloudinary integration)  
✨ Secure sessions and sanitation against NoSQL injection  
✨ Deployed and persistent data on MongoDB Atlas
